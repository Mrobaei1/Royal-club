## Calculation

`Overall % = sum(package weight × package completion %) / 100`

The package weights total 100%. A package earns progress only from implementation and test evidence; documentation alone does not close implementation work. Values below are package-level estimates reconciled against the current isolated research branch and its CI evidence. They do not mean the game is production-ready.
